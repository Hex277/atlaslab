Java (CheerpJ + ECJ) smoke test

Bu səhifə Claude tərəfindən brauzerdə TEST EDİLMƏYİB (sandbox-da CheerpJ-ə çıxış yoxdur). Məqsəd: Java dəstəyinin mümkün olub-olmadığını 2 dəqiqəyə göstərmək. Nəticəni (xüsusən ❌ olan addımı) mənə göndər.

Əvvəlcə ecj.jar faylını bu səhifənin yanına qoy (Eclipse Compiler for Java, ~2 MB — Maven Central: org.eclipse.jdt:ecj).
Sonra səhifəni lokal serverlə aç (məs. python3 -m http.server → http://localhost:8000/java-smoke-test.html).
